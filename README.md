# Website Development 2 — Labs & Assignment

Coursework repo for the Website Development 2 module, covers weekly labs
and the main assignment.

## Assignment: City Data Manager

A CRUD web application for managing city data objects — create, delete, filter and
search — built with HTML, CSS and JavaScript, using Fomantic UI components
(including collapsible panels and other UI plugins) to structure the interface.

**Live demo:** https://20117160-webdev2-labs.netlify.app/assignment/  
**Code:** [`/Assignment`](./Assignment)

## Built with

- HTML / CSS / JavaScript / Handlebars
- [Fomantic UI](https://fomantic-ui.com/)
- Deployed on [Netlify](https://www.netlify.com/)
